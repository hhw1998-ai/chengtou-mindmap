    • A｜认识对象3 模块 / 57 问题
      • M01｜概念与主体：先能准确说清在研究谁9 项
        首批
        • M01.1 城投究竟是什么
          • 分开企业名称、历史功能、实际业务、名单分类和当前监管身份；名字叫“产投”能证明哪些事，不能证明哪些事？
          • 区分城市建设投融资、土地整理、代建、城市运营、公用事业、产业投资，分别是谁的需求、谁付钱、谁承担风险？
          • 梳理“地方国企”“地方融资平台”“城投债发行人”的交集与差别；不能自行从公开名称推断内部名单状态。
        • M01.2 产投的几种实际形态
          • 区分经营产业、控股产业企业、少数股权投资、基金出资、基金管理和招商服务；各自靠什么取得收入或回报？
          • 区分国有资本投资公司、国有资本运营公司和一般产业投资企业；名称与取得专项改革授权分别是什么关系？
          • 区分集团总部、产业子集团、基金管理人、基金、项目公司、被投企业，画清法人和资金边界。
        • M01.3 几种“转型完成”不能混成一个结论
          • 分别识别融资平台退出、债券分类变化、经营模式改变、国资改革授权、组织整合的判断依据。
          • 比较“资产划入”“营收增长”“评级提高”“退出落袋”“经营改善”，每项究竟证明了什么？
          • 设计一个反例：更名、资产扩大、评级改善，但现金和经营能力没有改善，如何识别？
        • M01.4 六类容易混淆的关系
          • 政府与企业、财政与企业、出资人与企业、母子公司、管理人与基金、基金与被投企业，各是什么法律和经济关系？
          • 谁能布置任务、谁能签合同、谁能审批预算、谁享有投资收益、谁承担投资损失？
          • 同一个人兼任多个职务时，如何辨认其以什么身份作出什么决定？
        • M01.5 必修的经济与财务语言
          • 资产、净资产、资本金、负债、营业收入、利润、现金流各表示什么，为什么相互不能替代？
          • 控股、参股、实际控制、合并报表、权益法、公允价值变动分别怎样影响对企业的观察？
          • 认缴、实缴、投资成本、账面估值、已实现收益、现金分配分别是什么；基金规模究竟是哪一种？
        • M01.6 必修的管理语言
          • 治理决定谁有权作决定，管控决定集团怎样组织监督，流程决定事项怎样运行，三者怎样衔接？
          • 主责主业、战略、年度经营计划、预算、绩效责任书分别解决什么问题？
          • 岗位、职级、行政职务、工资总额、薪酬结构和中长期激励怎样区分？
        • 资料入口：公司章程、官网沿革、出资关系、公开债券文件；基础公司法、会计和国资知识。资料
        • 必须产出：术语卡、主体关系图、企业身份卡、六种“完成”对照表。产出
        • 过关标准：拿到一家陌生企业的简介，能指出已知身份、不能据此判断的身份，以及需要补查的材料；用白话解释上述术语而不依赖术语互相解释。过关
      • M02｜历史与底层逻辑：先理解旧模式如何运转4 项
        • M02.1 为什么会出现城投
          首批
          • 研究地方基础设施建设需求、财政收支安排和融资渠道之间的历史关系；按时期识别制度变化。
          • 不同城市为何形成建投、交投、水务、园区、文旅等不同平台组合，原有分工怎样影响今天的整合？
          • 区分当时合理的功能安排、后来形成的路径依赖、需要具体证据认定的问题。
        • M02.3 旧模式为何承压
          首批
          • 将财政与土地收入变化、项目回款、融资续接、利息负担、资产变现能力串成因果链。
          • 区分建设需求下降、财政支付慢、融资限制、资产收益低和管理低效，不能全称为“土地财政退潮”。
          • 用城市连续年度数据验证压力，研究逆向例子：土地收入下降时，哪些业务仍能稳定运转？
        • M02.4 各方究竟想通过转型得到什么
          首批
          • 政府可能关注公共服务、产业和财政可持续；出资人可能关注布局、资本回报和风险；企业关注生存、信用和发展。
          • 银行、债券投资者、员工、产业合作方分别关心什么，其目标怎样冲突？
          • 区分政策性目标、经营性目标、融资诉求和组织整合诉求，识别哪项是真正的首要问题。
        • M02.6 转型包含哪些相互牵制的变化
          首批
          • 分开财政债务关系变化、资产业务变化、组织能力变化和人员行为变化，分别由谁推动？
          • 化债、公共任务、产业培育和盈利目标之间，哪些冲突可以通过分类解决，哪些必须由股东作取舍？
          • 什么条件下应优先稳定现金、改善运营，什么条件下才有余力扩大产业投资？
      • M03｜政策适用：从“有哪些文件”走到“这件事该怎么判断”10 项
        待首批
        • M03.1 债务与平台治理线
          • 研究预算法及地方政府债务管理制度；区分法定政府债务、隐性债务、企业经营性债务、或有责任。
          • 研究新增债务约束、存量处置、融资平台退出、退出后监测各管什么，分别向谁核实？
          • 对报告提到的35、47、14、134、150号等简称，逐一核实完整身份、版本、适用范围和可取得性；未取得全文时不补写操作细则。
        • M03.2 公司治理与国资授权线
          疑首批
          • 研究公司法、企业国有资产法、党组织参与治理、董事会和经理层职责与当地实施安排。
          • 区分国资监管权、股东权、董事会职权与经理层经营权；“政府同意”能否替代公司治理程序？
          • 研究国有资本投资运营改革文件、授权清单及企业章程；中央企业做法哪些只能作比较参考？
        • M03.3 投资、产权交易与重组线
          • 对照当地投资管理、主业和负面清单要求，判断直投、并购、基金出资分别需要哪些程序。
          • 研究评估、备案或核准、进场交易、非公开协议和无偿划转的适用条件，不把重组当成一项工商动作。
          • 区分非金融企业国资、金融企业国资、上市公司、基金份额等不同交易对象可能适用的规则。
        • M03.4 政府投资基金与私募基金线
          • 先穿透资金性质：财政预算出资、委托国企出资、注资后专项用于基金、自有经营资金分别如何判断适用范围？
          • 研究政府基金定位、设立层级、投向、返投、登记、管理人、绩效和退出规则；基金是否私募还需核对相关监管要求。
          • 纳入2026年公开的布局投向与投向评价配套文件，区分发文日期、公开日期和实施条款，不能只按文号年份检索。
        • M03.5 绩效、工资与激励线
          • 研究本市经营业绩考核、工资总额、负责人薪酬、职业经理人、契约化管理和中长期激励规则。
          • 区分集团负责人、子企业负责人、职业经理人、普通员工、基金专业团队等人员适用范围。
          • 对跟投、超额收益分享、股权激励等工具分别查对象、权限、资金来源、会计税务和退出，不因“市场化”就假定可用。
        • M03.6 经营、招商和资产盘活线
          • 将政府采购、购买服务、特许经营、土地房产、招投标、税务和公平竞争要求映射到具体业务。
          • 研究招商任务与统一大市场、财政支持与企业经营、资源授权与公平竞争之间的边界。
          • REITs、资产证券化等工具须查基础资产、权属、收益、程序与成本；不能把工具名称当成适用条件已经具备。
        • M03.7 建立政策适用卡与冲突核查机制
          • 每条政策记录：原文、条款位置、发布主体、效力层级、时间、地域、对象、事项、例外、配套要求和核查状态。
          • 标注“禁止、应当、可以、鼓励、试点、需批准”等措辞差异，输出对当前事项的实际影响。
          • 分开正式文件、官方解读、公开审核规则、非公开执行口径、市场传闻和研究者建议；不把“335”“224”等市场说法设为统一转型标准。
        • 资料入口：政府、财政、国资、人社、发改、证监、交易所和相关协会的正式渠道；当地及企业制度。资料
        • 必须产出：政策台账、适用矩阵、待核实口径表、典型事项政策判断卡。首批来源见附录A。产出
        • 过关标准：面对“能否出资设基金”“能否给团队超额收益分享”等具体问题，能列出适用判断、必要前提和缺失信息，而非只贴政策标题。过关
    • B｜看清家底1 模块 / 9 问题
      • M04｜区域与股东：弄清这家企业为何存在3 项
        • M04.2 区域产业基础
          待首批
          • 拆产业链、龙头、配套、人才、能源、物流、土地和研发条件；从“有产业规划”追到“有真实需求”。
          • 区分产业规模大、产业利润高、适合地方培育和适合集团投资，四者为何不等同？
          • 研究本地企业真正缺的是资本、订单、空间、技术、管理还是渠道；不同缺口需要什么工具？
        • M04.3 市属国资版图
          首批
          • 梳理本市城投、交投、产投、资本运营、园区、水务、文旅等主体的定位、资产和功能重叠。
          • 哪些资产由企业拥有，哪些仅被委托管理；哪些资源属于其他层级或部门，不能假定可划入？
          • 集团为什么承担这项任务，有无替代主体，是否正在重复建设能力？
        • M04.5 利益相关方与行为动机
          首批
          • 政府部门、出资人、总部、原平台、子公司、债权人、员工和合作方各自会失去或得到什么？
          • 资金统筹、资产划转、人事调整和收入分配会改变哪些既有利益？
          • 哪些阻力来自信息、能力或不信任，哪些来自目标和利益确实不一致？
    • C｜判断怎么转3 模块 / 36 问题
      • M06｜目标与路径：先判断该往哪里转1 项
        • M06.2 做路径比较
          首批
          • 分别比较城市运营、公用事业、园区服务、产业经营、股权投资、资本运营和先稳经营处置存量。
          • 每条路径要列客户、支付方、投入、现金周期、团队要求、风险、政策条件和协同。
          • 区分当前可做、补齐条件后可做、长期不适合做，不把组合发展理解为每条路径都做。
      • M07｜经营业务：弄清集团靠什么持续取得现金3 项
        • M07.1 城建代建与工程业务
          首批
          • 委托、施工、代建、投资和融资责任分别由谁承担，收入确认和结算回款如何发生？
          • 查建设成本、管理费、融资成本、审计结算和回款周期，区分“有工程”和“有利润”。
          • 转型后哪些存量项目必须继续履行，怎样避免停止旧模式时留下无资金项目？
        • M07.2 园区与产业载体
          首批
          • 从拿地、建设、招商、租售、物业到企业服务复原商业模式，谁为每项服务付费？
          • 出租率、实际收缴、租金、维护、融资和再投资如何共同决定现金回报？
          • 产业招商、载体出租和股权投资之间有无真实协同，是否反而形成低租金和高投入负担？
        • M07.5 产业经营、并购与供应链
          首批
          • 控股实业企业怎样形成产品、客户、毛利、周转和研发能力，与少数股权投资有什么不同？
          • 并购取得的利润、负债、商誉、或有责任和管理难度怎样进入集团？
          • 贸易业务需要验证哪些真实交易、信用和货权条件，哪些收入增长伴随更大的现金风险？
      • M08｜产业投资与基金：把募、投、管、退拆开研究10 项
        待首批
        • M08.1 工具和资金性质先行
          • 比较直投、基金LP出资、管理基金、控股并购和招商服务，分别赚什么钱、承担什么责任？
          • 穿透资金来源和用途约束，识别财政资金、受托资金和企业资金的边界。
          • 为什么集团、管理人、基金和被投企业之间的现金不能直接当作集团自由现金？
        • M08.2 是否需要基金
          • 先问设立目的、项目来源、资金匹配和管理能力，再比较参投已有基金与自设基金。
          • 基金规模、实缴进度、期限、费用、决策权和退出安排如何影响实际效果？
          • 无基金是否仍能实现产业目标；有基金是否反而增加资金闲置、重复收费和治理层次？
        • M08.3 募资与管理人选择
          • LP为何出资，政府、国企、金融机构和市场化资本的收益与期限要求有什么差别？
          • 查GP或管理人的历史业绩、团队稳定性、真实退出、利益冲突和投后能力。
          • 区分管理规模、认缴规模、可投资金额、实投金额和实际带动社会资本，统一统计口径。
        • M08.4 项目筛选、尽调与估值
          • 将产业研究、项目来源、初筛、技术市场财务法律尽调、估值和风险审查逐步连起来。
          • 每阶段什么证据足以继续，什么问题必须补查，什么问题应否决？
          • 研究订单、技术成熟度、客户集中、资金消耗、关联交易、估值假设和退出买方，避免以赛道热度代替判断。
        • M08.5 投决与协议
          • 核对股东、董事会、经理层、投委会、基金合伙协议各自权限；不能预设所有投委会都只有咨询权或都有最终决定权。
          • 研究出资条件、分期、治理权、反稀释、回购、优先权等条款的作用、约束和可执行性。
          • 招商谈判、专业判断和公司治理程序如何衔接，谁记录反对意见和剩余风险？
        • M08.6 投后管理与风险处置
          • 分别研究参股与控股企业的信息权、董事履职、经营监测、资源服务和重大事项处理。
          • 追加投资的依据是什么，怎样区分合理续投与为掩盖失败不断追加？
          • 经营不达预期、估值下调、违约和控制权变化如何触发分级处置与责任记录？
        • M08.7 退出与组合评价
          • 比较股权转让、并购、上市后减持、回购、基金份额转让和清算，逐项查条件、买方、时间、成本和国资程序。
          • REITs针对符合条件的基础设施等资产安排，不能当成一般未上市科技股权的通用退出通道；S基金也不保证有买方或合理价格。
          • 研究IRR、DPI、TVPI及已实现现金，区分项目回报、基金回报、LP净回报、区域产业效果，不能相互替代。
